# DevHub 0.0.2

- Fixed the crash when opening a project's SQLite database read-only. Project sessions now use one native SQLite engine for opening, schema inspection, browsing, queries, backups, and visual edits.
- Preserved SQLite storage types for native bound parameters, including REAL values, binary fingerprints, SQL NULL, and signed 64-bit integers.
- Fixed the MSVC CI build failure caused by Windows `min` and `max` macros interfering with numeric-limit assertions in the feature regression suite.

Extract the entire Windows portable ZIP and launch `bin/devhub.exe`. Keep its runtime DLLs, plugins, and QML folders together.
